# Punto de Venta

## Descripción

Este es un sistema de punto de venta diseñado para gestionar ventas, inventario y clientes de manera eficiente.

## Características
- Gestión de productos
- Registro de ventas
- Control de inventario
- Informes generales

## Requisitos
- Node.js
- npm
- Base de datos (MySQL, PostgreSQL, etc.)

## Instalación
1. Clonar el repositorio
2. Instalar dependencias: `npm install`
3. Configurar la base de datos
4. Ejecutar la aplicación: `npm start`

## Uso
- Acceder al servidor en http://localhost:3000
- Iniciar sesión con credenciales administrativas
- Utilizar el sistema para registrar ventas y gestionar inventario
